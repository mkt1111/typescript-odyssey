# TypeScript Odyssey

A tutorial site that walks through core TypeScript topics, ending with a quiz.

## Features

- Topic pages: Introduction, Basic Types, Functions, Interfaces, Classes, Generics
- Code examples on each topic page
- Multiple-choice quiz with a results screen
- Sidebar navigation between topics

## Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui (Radix UI)
- React Router
- TanStack Query
- lucide-react

## Running locally

Requires Node.js and npm.

```sh
npm install
npm run dev
```

## How it was built

Built with Lovable (AI app builder) under Matthew Thornhill's direction as a learning/exploration project.
